# SEEDU:ON — 전체 20개 파일 통합본

이 버전은 이전 **학과별 점수 산정 이유 전체 20개 파일**에 최근 **공통 강점·보완 카드 삭제 + 5대 역량 핵심 근거 최대 3개** 패치를 합친 뒤, 학과 카드 화면을 정리한 것입니다.

## 이번 화면 변경
- 학과명 바로 아래 자동 생성 추천 요약 문장 제거
- `추천 근거 원문 보기` 유지 (분석 응답에 전달된 원문 근거 표시)
- 학과 평가 맨 아래 `보완 방향` 문장 및 `보완 안내 원문 보기` 제거
- 5개 평가 영역 옆 `근거 20/30`처럼 보이는 배점 비율 제거, 부분 점수만 표시
- `점수 산정 이유 보기`의 16개 세부 지표, 등급, 계산식, N/E, 실제 연결 근거는 유지
- 공통 5대 역량 강점·보완 카드 삭제 및 핵심 평가 근거 최대 3개 표시 유지
- 기존 로그인, 레이더 그래프, 학과 추천, 로드맵 등 유지

## 업로드 방법
1. 기존 GitHub 저장소를 백업하세요. **GitHub 파일을 먼저 전부 삭제하지 마세요.**
2. ZIP을 풀고 폴더 **안의** 파일과 `frontend` 폴더를 저장소 최상위에 업로드하세요. (ZIP 자체를 올리지 않음)
3. 같은 경로의 파일은 교체됩니다. 이름이 다른 이전 파일은 GitHub에서 자동으로 삭제되지 않습니다.
4. Vercel Root Directory가 `./`(저장소 최상위)인지 확인하세요. 이 ZIP은 최상위 `index.html`을 사용합니다.
5. Render 환경 변수(`OPENAI_API_KEY`, `OPENAI_MODEL`, `DATABASE_URL` 등)는 건드리지 마세요.

## 검증 및 한계
- 20개 파일 구조, Python/JS 문법, ZIP 무결성을 확인했습니다.
- 실제 배포, API 호출, 데이터베이스 로그인, 브라우저 화면은 검증하지 않았습니다.
- `추천 근거 원문 보기`에 표시되는 내용은 서버에서 분석 응답으로 전달된 텍스트입니다. 서버가 이미 생략하거나 잘라 보냈다면 전체 학생부 원문과 동일하지 않을 수 있습니다.
- 근거 부족은 낮은 점수와 동일하지 않습니다. N/E 평가 보류 상태를 유지합니다.
